# HabitCraft - Умный трекер привычек

C++ приложение с PostgreSQL для отслеживания и анализа привычек.

## Возможности

- **Добавление привычек** с целями и описаниями
- **Отслеживание выполнения** с заметками и оценками
- **Аналитика привычек** - сила привычки в %, слабые дни недели
- **Трекинг серий** - текущие стрики выполнения  
- **Визуализация прогресса** - прогресс-бары в консоли
- **Удаление привычки** - если уже не актуально, можно удалить

## Технологии

- C++17 с CMake
- PostgreSQL + libpqxx
- Сложные SQL запросы с оконными функциями и CTE
- Интерактивный консольный интерфейс

## Запускс

```bash
mkdir build && cd build
cmake ..
make
./HabitCraft
```
