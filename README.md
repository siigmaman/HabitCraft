# HabitCraft - Умный трекер привычек

Telegram бот для отслеживания и анализа привычек с продвинутой аналитикой.

## Возможности

- **Добавление привычек** с настраиваемой частотой и описанием
- **Отслеживание выполнения** с заметками и оценками
- **Визуализация прогресса** - прогресс-бары за неделю
- **Аналитика привычек** - сила привычки в %, слабые дни недели
- **Трекинг серий** - текущие стрики выполнения
- **Управление через Telegram** - интуитивный интерфейс с кнопками
- **Удаление привычек** - полное управление списком привычек

## Технологии

### Backend
- **C++17** - основной язык программирования
- **CMake** - система сборки
- **libpqxx** - C++ клиент для PostgreSQL
- **nlohmann/json** - работа с JSON
- **libcurl** - HTTP запросы к Telegram API

### База данных
- **PostgreSQL** - реляционная база данных
- **Сложные SQL запросы** с оконными функциями и CTE
- **Каскадное удаление** - автоматическая очистка связанных данных

### Внешние сервисы
- **Telegram Bot API** - платформа для бота
- **Long Polling** - получение обновлений от Telegram

### Архитектурные особенности
- **Многопоточность** - обработка запросов с std::mutex
- **Состояния пользователей** - FSM для многошаговых операций
- **Обработка ошибок** - устойчивость к сетевым сбоям
- **Автоматический перезапуск** - самовосстановление при ошибках

## Установка и запуск

```bash
# Сборка проекта
mkdir build && cd build
cmake ..
make

# Запуск бота
./habitcraft-bot
```
